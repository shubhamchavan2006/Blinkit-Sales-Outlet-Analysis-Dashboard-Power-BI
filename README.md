# 🛒 Blinkit Sales & Outlet Analysis Dashboard | Power BI

An interactive and fully automated **Power BI dashboard** built to analyze Blinkit's sales performance, outlet characteristics, product categories, and business trends.

The dashboard includes interactive **slicers, filters, KPIs, and visualizations** that automatically update based on user selections.

## 🎯 Project Objective

The objective of this project is to analyze Blinkit sales data and identify important business patterns related to:

* Overall sales performance
* Product and item categories
* Fat content
* Outlet location and tier
* Outlet size
* Outlet establishment trends
* Average sales
* Average ratings
* Number of items

---

## 📌 Key KPIs

The dashboard provides four major KPIs:

* **Total Sales**
* **Average Sales**
* **No. of Items**
* **Average Rating**

These KPIs dynamically change according to the selected slicers and filters.

## 🎛️ Interactive Features

The dashboard is fully automated and interactive with:

* **Outlet Location Type slicer**
* **Item Type slicer**
* **Outlet Size slicer**
* Interactive filtering
* Cross-filtering between visuals
* Dynamic KPI updates
* Automatic chart updates
* Interactive data exploration

Selecting a value from the slicers automatically updates the relevant KPIs and visualizations.

---

## 🔍 Key Insights

Some key insights from the dashboard include:

* **Tier 3 outlets** generate the highest sales among the three outlet location types.
* **Fruits & Vegetables** is the highest-selling item category.
* **Snack Foods** is another major contributor to overall sales.
* **Medium-sized outlets** contribute the largest share of sales.
* **Regular-fat products** account for a larger share of sales than Low-Fat products.
* Outlet sales show significant variation across establishment years, with a noticeable peak around **2018**.

## 🚀 How to Use

1. Download the `blinkit.pbix` file from this repository.

3. Use the slicers on the left side to filter the dashboard.
4. Select different categories and visuals to explore the data.
5. Observe how the KPIs and charts automatically update.
